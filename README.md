# Protocol-RED 맵 제작 도구

위에서 내려다보는 2D 픽셀 게임의 맵을 만들고, 맵 수십 개를 순서대로 관리하는 도구예요. 설치할 게 없어요.

## 열기

`index.html` 파일을 **더블클릭**하면 브라우저에서 열려요.

- **Chrome이나 Edge로 열어 주세요.** 다른 브라우저에서는 맵 목록과 편집 화면이 서로 맵을 못 볼 수 있어요.
- 항상 **같은 브라우저, 같은 파일 위치**에서 열어야 만든 맵이 보여요.

## 맵 만들기

1. 맵 목록에서 **＋ 새 맵**을 누르고 이름과 크기(가로·세로 칸 수)를 정해요. 기본은 40×30칸, 가장 크게는 200×200칸이에요.
2. 만든 맵의 **열기**를 누르면 편집 화면이 열려요.
3. 왼쪽에서 **층**(바닥 / 물건)과 종류 탭을 고르고, 블록을 눌러 고른 다음 맵을 클릭해요. 누른 채 끌면 쭉 이어서 놓여요.
   - **바닥** 층에는 땅 타일, **물건** 층에는 벽·상자·건물처럼 바닥 위에 올라가는 것을 놓아요.
   - 한 층에서 블록끼리는 겹치지 않아요. 새 블록을 놓으면 겹친 블록은 통째로 바뀌어요.
   - 여러 칸짜리 건물은 가장자리에 걸치면 놓이지 않아요.

| 도구 | 하는 일 |
|---|---|
| 붓 | 블록을 하나씩, 또는 끌어서 이어서 놓기 |
| 사각형 | 끌어서 영역을 한 번에 채우기 |
| 지우개 | 선택한 층의 블록 지우기 |

- **되돌리기 / 다시하기**: 위쪽 버튼 또는 `Ctrl+Z`, `Ctrl+Y`(맥은 `Cmd`). 끌어서 놓은 건 한 번에 되돌려져요.
- **확대·축소**: 마우스 휠, 또는 아래 `−` `＋` 버튼. **전체 보기**를 누르면 맵 전체가 한눈에 보여요.
- **화면 이동**: 마우스 **오른쪽 버튼**을 누른 채 끌기(블록은 놓이지 않아요). 스페이스바를 누른 채 끌기, 마우스 가운데 버튼으로 끌기도 돼요.
- **격자**: 칸 선을 켜고 끌 수 있어요.
- **크기 변경**: 위쪽 버튼. 줄이면 밖으로 나가는 블록이 사라지는데, 몇 개인지 알려주고 확인해요. 크기를 바꾸면 되돌리기 기록이 지워져요.

## 꼭 해 두세요: 백업

맵은 이 브라우저 안에 **자동으로 저장**돼요. 그런데 브라우저 기록을 지우면 맵도 같이 사라질 수 있어요.

- 맵 목록 위쪽의 **전체 내보내기**를 눌러 파일(`protocol-red-maps-날짜.json`)을 받아 두세요. 가끔, 그리고 큰 작업 뒤에 꼭요.
- 받은 파일을 Claude에게 주면 프로젝트 폴더(`data/maps/`)에 정식으로 보관해 줘요.
- **불러오기**로 그 파일을 다시 올리면 맵이 **추가**돼요(기존 맵은 지워지지 않아요).
- 저장 공간이 가득 차면 화면에 노란 경고가 떠요. 그때는 바로 내보내기를 해 주세요.

## 블록 그림 만들기 (챗지피티에게 요청할 때)

> 2D 탑다운 픽셀 게임용 타일입니다. 한 칸은 정확히 64×64 픽셀로, 투명 배경 PNG 파일로 만들어 주세요. 각 칸은 틈이나 테두리, 글자 없이 같은 크기로 가로세로 격자에 맞춰 나열하고, 칸 안에서 그림이 잘리지 않게 해주세요.

- 한 칸은 **64×64**예요. 큰 구조물은 64의 배수로 만들어 주세요(가로 3칸, 세로 2칸이면 192×128).
- 한 장에 여러 블록을 격자로 모아서 줘도 돼요. Claude가 칸 크기대로 잘라서 등록해요.
- 블록마다 **이름**과 **걸어갈 수 있는지/막히는지**를 알려 주세요.
- 블록이 하나도 없는 층은 "아직 블록이 없어요"라고 안내가 보여요.

### 개발자용: 블록 등록 방법

`data/blocks.js`가 블록 정식 목록이고, 그림 파일은 `assets/blocks/`에 있어요. 그림 검사와 자르기는 도구로 해요(처음 한 번 `npm install`).

```bash
node tools/slice-sheet.js sheet.png --prefix wall --names "벽,벽 모서리" --layer objects --category 벽 --out assets/blocks
```

큰 구조물 한 장은 `--whole`을 붙이면 자르지 않고 칸 수(너비÷64, 높이÷64)로 등록해요. 출력된 줄을 `data/blocks.js`에 붙여 넣으면 돼요.

## 맵 파일 형식 (개발자용)

맵은 맵마다 JSON이에요. 나중에 게임 프로그램(Godot 등)에서도 읽기 쉬운 일반 형식이에요.

| 필드 | 뜻 |
|---|---|
| `version` | 파일 형식 버전 (지금은 1) |
| `id`, `name` | 맵 번호표와 이름 |
| `width`, `height`, `tileSize` | 가로·세로 칸 수, 한 칸 크기(64) |
| `floor`, `objects` | 층별 블록 목록. 항목은 `[블록id, x, y, n]` — (x, y)부터 가로로 `n`개(블록 너비 간격) |
| `start`, `exits` | 지금은 쓰지 않아요(새로 만든 맵은 `null`과 빈 목록). 나중에 게임 연결 때 시작 지점·출구가 필요하면 다시 켤 수 있어요 |

여러 칸 블록의 `x, y`는 왼쪽 위 칸이에요. 블록의 크기와 통과 가능 여부는 `data/blocks.js`에 있어요.
